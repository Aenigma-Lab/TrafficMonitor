# 🚗 TrafficMonitor

[![GitHub](https://img.shields.io/badge/GitHub-Repository-blue?logo=github)](https://github.com/zhongyang219/TrafficMonitor)
[![Version](https://img.shields.io/badge/Version-1.85.1-green)](https://github.com/zhongyang219/TrafficMonitor/releases)

A lightweight and powerful system monitor for Windows that displays real-time network traffic, CPU usage, memory, GPU, temperatures, and more directly in the taskbar or as a floating window. Supports customizable skins, notifications, and portable mode for easy deployment.

## ✨ Features

- 📊 **Real-time Monitoring**: Track network upload/download speeds, CPU usage, memory consumption, GPU performance, and hardware temperatures.
- 🎨 **Customizable Skins**: Choose from multiple built-in skins or create your own with custom backgrounds and layouts.
- 🔔 **Notifications**: Set alerts for high CPU/memory usage, temperatures, or traffic thresholds.
- 📱 **Taskbar Integration**: Display information directly in the Windows taskbar with color-coded indicators.
- 🔧 **Portable Mode**: Run without installation, perfect for USB drives or temporary setups.
- 🌐 **Multi-language Support**: Available in multiple languages for global users.
- ⚙️ **Extensive Configuration**: Fine-tune display options, fonts, colors, and more via intuitive settings.
- 📈 **Historical Data**: View traffic history with logarithmic scaling and customizable views.

## 📥 Installation

1. Download the latest release from the [GitHub Releases](https://github.com/zhongyang219/TrafficMonitor/releases) page.
2. Extract the ZIP file to your desired location.
3. Run `TrafficMonitor.exe` to start the application.
4. For portable mode, ensure `global_cfg.ini` has `portable_mode = true`.

### System Requirements
- Windows 7 or later
- .NET Framework (if not already installed)

## 🚀 Usage

1. **First Launch**: The application will appear in the taskbar. Right-click the icon for options.
2. **Configuration**: Access settings via the context menu to customize display items, skins, and notifications.
3. **Monitoring**: View real-time stats in the taskbar or floating window. Double-click to open Task Manager.
4. **Skins**: Switch skins from the settings to change appearance and layout.

### Key Shortcuts
- Double-click taskbar icon: Open Task Manager
- Right-click: Access context menu for settings and options
